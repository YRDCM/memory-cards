# 记忆卡片盒 · 线上部署说明

## 地址

**https://mystarwhisper.cn/english/**

手机和电脑都用这个地址。打开后可以在浏览器菜单里「添加到主屏幕」，当成 App 用。

---

## 手机和电脑同步（3 步）

1. 电脑上打开上面地址 → 设置 → 多设备同步 → 点「生成」，会出现一串 24 位同步码
2. 手机上打开同一个地址 → 设置 → 多设备同步 → 把那串码粘进去 → 点「启用」
3. 页面底部会显示「已同步 · HH:MM」

之后两台设备各学各的，进度会自动合并：

- **每个词**取「最近一次复习」的那份，不会因为同步把一个词打回原形
- **每天的记录**取两边较多的那份
- **自己导入的词**取并集
- 学习中的改动最多 2 分钟推一次，切走/关页面时会补推一次

> 同步码就是密码。任何人拿到它都能读写你的进度，别发到公开群里。
> 忘了同步码不用慌：重新生成一个，再从任意一台有数据的设备上「启用」一次，数据就搬过去了。

## 服务器上有什么

| 项目 | 位置 |
|---|---|
| 网页文件 | `/opt/english-coach/web/index.html` |
| 同步服务代码 | `/opt/english-coach/sync_server.py` |
| 同步数据 | `/opt/english-coach/data/<同步码>.json` |
| 服务名 | `english-sync.service`（systemd，开机自启，挂了 3 秒重拉） |
| 监听 | `127.0.0.1:8093`（只对本机，公网访问走 nginx 反代） |
| 入口 | `https://mystarwhisper.cn/english/` |
| 接口 | `/english/api/state?code=xxx`（GET 拉、PUT 推、409 表示版本冲突） |

nginx 的改动是在 `starwhisper.conf` 和 `starwhisper-domain.conf` 里各插了一段带
`# ---- english-coach ----` 标记的配置，原文件备份在同目录的 `.bak-eng-<时间戳>`。

## 出问题怎么办

```bash
# 看同步服务状态和日志
systemctl status english-sync
journalctl -u english-sync -n 50 --no-pager

# 接口探活
curl -s https://mystarwhisper.cn/english/api/ping
```

**页面 404 / 502**：多半是 nginx 配置没生效

```bash
sudo nginx -t
ls /etc/nginx/conf.d/*.bak-eng-*        # 找备份
sudo cp <备份文件> /etc/nginx/conf.d/starwhisper.conf
sudo cp <备份文件> /etc/nginx/conf.d/starwhisper-domain.conf
sudo systemctl reload nginx
```

**误删了数据文件**：每台设备的浏览器里还有一份完整进度，重新打开页面会自动补推上去。

## 安全说明

- 同步接口只能通过 `/english/api/` 访问，没有账号体系，**同步码就是唯一凭据**
- 数据文件权限 `700` 目录，只有 `dsh` 用户能读
- 页面加了 `noindex`，不会被搜索引擎收录
- 主站「星语 StarWhisper」没有受到任何改动影响（已回归验证 HTTPS + IP 两种访问）
