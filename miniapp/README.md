# 记忆卡片盒 · 微信小程序

英语背单词小程序，间隔重复 + 多设备同步。

## 打开方式

1. 微信开发者工具 → 导入项目
2. 目录选这个 `miniprogram` 文件夹
3. AppID 先填 `touristappid`（游客模式）也能跑
4. 编译预览

## 换成你自己的小程序

注册完小程序后，改两处：

1. `project.config.json` 里的 `"appid"` 换成你的 AppID
2. 小程序后台 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名加上
   `https://mystarwhisper.cn`

不加第 2 步，同步会失败（其余功能都正常）。

开发阶段可以在开发者工具「详情 → 本地设置」勾选 **不校验合法域名**，先跳过这一步。

## 发音（需要配置插件）

单词发音走微信官方「微信同声传译」插件（WechatSI）：

1. 小程序后台 → **设置 → 第三方设置 → 插件管理 → 添加插件**
2. 搜「微信同声传译」（AppID `wx069ba97219f66d99`）并添加
3. 添加成功后，`app.json` 里已声明的 `plugins.WechatSI` 才会生效

**没添加插件就编译会报「插件未授权」**，这是预期的——先去后台加。
该插件目前要求小程序已认证，未认证的账号在插件管理里搜不到。

代码在 `utils/tts.js`：拿不到插件时 `available()` 返回 false，发音按钮自动隐藏，
不会报错、不影响背单词。

## 和网页版的差异

| | 网页版 | 小程序 |
|---|---|---|
| 地址 | mystarwhisper.cn/english/ | 微信里打开 |
| 发音 | 浏览器语音合成 | **暂不支持**（后续可接同声传译插件） |
| 存储 | localStorage | 本地缓存（两边数据不互通，靠同步码合并） |
| 同步 | 同域名相对路径 | 需配置服务器域名白名单 |

同步码和网页版通用：网页上生成的码，小程序里填同一个就能共用进度。
