# 记忆卡片盒 · Memory Cards

英语背单词工具。核心是两件事：**间隔重复**（该复习的词自动排到你面前）和**监督**（不做就催你）。

三个端，一个后端：

| 目录 | 是什么 | 怎么跑 |
|---|---|---|
| `web/` | 网页版（PC + 手机浏览器） | `node build.mjs` → 生成 `dist/index.html` |
| `miniapp/` | 微信小程序 | 微信开发者工具导入这个目录 |
| `server/` | 后端：多设备同步接口（Python 3） | systemd 托管，见 `web/部署说明.md` |
| `dist/` | 网页版构建产物 | 上传到服务器 |

## 线上地址

网页版：**https://mystarwhisper.cn/english/**

## 词库

| 库 | 词条 | 带例句 |
|---|---:|---:|
| 初中 | 1,985 | 89% |
| 高中 | 3,743 | 85% |
| 四级 | 4,543 | 85% |
| **去重合计** | **5,662** | |

「全部」范围按 初中 → 高中 → 四级 的顺序推进，每本书内部按首字母轮转排序。

词库是从公开数据构建的，源头在 `web/raw/`（不在版本控制里），生成脚本 `web/_build-deck.mjs`，
会同时输出 `web/deck*.js`（网页版）和 `miniapp/data/deck*.js`（小程序），两边永远一致。

## 数据存在哪

- 网页版：浏览器 localStorage
- 小程序：小程序本地缓存
- **两边不互通**，靠同步码合并：任一端生成 24 位同步码，另一端填进去即可

同步服务只存一份 JSON（按同步码），合并规则：每个词取「最近复习」的那份，绝不丢词。

## 改代码

```bash
# 网页版
cd web && node build.mjs          # → dist/index.html

# 词库重新生成（需要 web/raw/ 下的原始数据）
cd web && node _build-deck.mjs

# 小程序：直接用开发者工具打开 miniapp/ 目录
```

## 三个端的差异

| | 网页版 | 小程序 |
|---|---|---|
| 发音 | 浏览器语音合成 | 暂无（需接同声传译插件） |
| 提醒推送 | 页面上催 | 暂无（需订阅消息） |
| 安装 | 浏览器打开即用 | 需注册审核 |

网页版的功能清单、部署步骤、回滚办法见 [`web/部署说明.md`](web/部署说明.md)。
